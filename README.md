# SmartStore Helper

네이버 스마트스토어 상품등록 작업을 자동화하기 위한 Chrome 확장 프로그램입니다.

## 설치 및 실행 방법

### 1. 프로그램 다운로드
1. GitHub 저장소 상단의 **Code** 버튼을 클릭합니다.
2. **Download ZIP**을 선택하여 파일을 다운로드합니다.
3. 다운로드한 ZIP 파일의 압축을 해제합니다.

### 2. Chrome 확장 프로그램 설치
1. Chrome 브라우저를 실행합니다.
2. 주소창에 `chrome://extensions`를 입력하여 이동합니다.
3. 우측 상단의 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
5. 압축 해제한 폴더 중 `manifest.json` 파일이 있는 폴더를 선택합니다.

### 3. 프로그램 실행
1. 네이버 스마트스토어 판매자센터에 접속합니다.
2. 상품등록 또는 상품수정 페이지로 이동합니다.
3. Chrome 확장 프로그램 목록에서 **SmartStore Helper**를 실행합니다.
4. 필요한 정보를 입력한 후 **입력한 값 반영** 버튼을 클릭합니다.

## 주의사항
- Chrome 브라우저에서 사용해야 합니다.
- 압축파일을 해제한 후 확장 프로그램을 등록해야 합니다.
- 프로그램이 정상적으로 작동하려면 설치 폴더 안에 `manifest.json`, `content.js`, `inject.js`, `popup.html`, `popup.js` 파일이 있어야 합니다.
- 설치한 폴더를 삭제하거나 이동하면 확장 프로그램이 정상적으로 실행되지 않을 수 있습니다.
- 스마트스토어 화면 구조가 변경되면 일부 자동화 기능이 정상 작동하지 않을 수 있습니다.
